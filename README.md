Task 1: Hangman Game

Description

Hangman is a word-guessing game developed using Python. The player tries to guess a hidden word one letter at a time.

Features

- Random word guessing.
- Accepts letter guesses from the player.
- Displays correctly guessed letters.
- Limits the number of incorrect guesses.
- Shows whether the player wins or loses.

Technology Used

- Python 3

How to Run

1. Download or clone this repository.
2. Open the project folder in a terminal.
3. Run the command:

"python hangman_game.py"
